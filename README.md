# Vamsi Creates Carousel Skill

An agent skill for turning supplied information into an editable Canva social media carousel using the Vamsi Creates visual style.

## How to use

1. Copy `skills/vamsi-creates-carousel/` into your agent’s skills directory, or open its [SKILL.md](skills/vamsi-creates-carousel/SKILL.md) in an agent that can use Canva.
2. Connect the agent to Canva and provide the source text, intended audience, desired slide count, and any call to action.
3. Ask: “Use the Vamsi Creates carousel skill to make an editable 4:5 Canva carousel from this material.”
4. Review the editable Canva link. Check facts, text wraps, image sources, and the final slide before exporting or publishing.

The skill defaults to Poppins, a blue accent, white content slides, and a dark navy closing slide. See [design-system.md](skills/vamsi-creates-carousel/references/design-system.md) for visual specifications.
